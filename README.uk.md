# mikrotik-swos-mcp

MCP-сервер, через який ШІ-асистент (Claude Code, Claude Desktop чи будь-який MCP-клієнт) **читає й змінює комутатори
MikroTik SwOS / SwOS Lite наживо** через їхній веб-API, без ручного скачування й заливання `.swb`.
Повний опис англійською: [README.md](README.md).

- **Без зашитих таблиць полів.** Сервер читає `engine.js` самого комутатора й бере звідти id полів, назви, типи, списки
  опцій і форми веб-UI. Мініфіковані імена різні в кожній збірці SwOS, парсер це враховує.
- **Запис як у веб-UI.** Один POST форми на `/<секція>.b` застосовується одразу, без перезавантаження.
- **Безпечно за замовчуванням.** Кожен запис спершу повертає dry run (було -> стане) і токен. Застосовується лише з
  `confirm=<токен>`, і токен не спрацює, якщо конфіг на комутаторі змінився. Після запису: зчитування назад,
  запис у журнал змін і свіжий бекап.
- **Бекапи з назвами полів.** `.swb` декодується; можна порівняти комутатор із файлом або файл із файлом.
  Підготовлений `.swb` можна відновити наживо: застосовуються лише форми, що відрізняються, без перезавантаження.
- **Не навантажує робочі комутатори.** Один запит за раз, пауза 0,2 с, кеш 3 с, жодного фонового опитування.

Перевірено: **CSS610-8G-2S+, SwOS Lite 2.21**, три робочі комутатори. 3 251 значення, які показує веб-UI, збігаються з
декодером (0 розбіжностей, інструмент `verify/`). 2.18 працював у роботі до оновлення. Парсер також перевірено на 2.20 і на
CSS610-8P (PoE) з довідкових файлів lanrat/python-mikrotik-swos. Повний SwOS (CRS3xx, CSS326) поки не підтримується.

## Швидкий старт
```bash
pip install -r requirements.txt
cp switches.example.json switches.json        # вписати IP комутаторів
claude mcp add swos --scope user -- /шлях/до/python /шлях/до/mikrotik-swos-mcp/server.py
```
Паролі: поле `password` у `switches.json` або змінні середовища `SWOS_PASSWORD_192_168_88_1` / `SWOS_PASSWORD`.
Сервер паролі ніде не друкує й не зберігає. Порожній пароль дає лише попередження.

Інструменти: `list_switches`, `read_config`, `read_status`, `diff_configs`, `set_identity`, `set_port`, `set_vlan`,
`set_field`, `save_backup`, `restore_backup` (таблиця в [README.md](README.md#tools)).
